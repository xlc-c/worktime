# 计费（Billing）

WorkTime 默认是“看清时间去哪了”。如果你按小时收费，可以给事项加单价，直接出工时单。

## 事项层级与费率继承

事项名用 ` / ` 分层：`客户A / 项目B / 对账`。费率只写在有意义的层级上，子级自动继承：

```
客户A                800 元/小时
└─ 项目B             （继承 800）
   ├─ 对账           （继承 800）
   └─ 会议           （继承 800）
客户C                600 元/小时，billable = false
```

再加子级单价即可覆盖；`billable = false` 的事项不计费（内部会议、行政）。

## 命令

```bat
:: 设置费率
wt matter set --path "客户A" --rate 800 --currency CNY
wt matter set --path "客户C" --rate 600 --billable 0
wt matter list

:: 出工时单（Markdown + CSV）
wt invoice --date 2026-11-30 --period month
```

产物在 `data/reports/<结束日期>-invoice.md` 和 `data/exports/<结束日期>-invoice.csv`。

## 复核页

`⚙ 设置 → 计费`：表格里直接改单价/币种/是否计费，或新增事项；「查看本月费用」给出合计。

周报/月报/年报里如果存在费率，会自动多出「工时(h)」「金额」两列，并加一行计费合计。

## 取整

`config.json` → `report.round_minutes`，默认 `6`（0.1 小时）。

| 值 | 效果 |
| --- | --- |
| `0` | 精确到 0.001 小时 |
| `6` | 就近取整到 6 分钟（律所/咨询常见） |
| `15` | 就近取整到一刻钟 |

合计金额按取整后的工时计算，和发票口径一致。

## 明确不做

- 不做发票号、税率、付款状态、客户审批流——这是时间统计工具，不是财务系统。
- 不把费率发给任何服务器；导出只在本地生成文件。
