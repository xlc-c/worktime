## 1. 软件组成与运行方式

| 组件 | 说明 | 权限 |
|---|---|---|
| `runtime\python.exe` | CPython 3.10+ 便携运行时（仅标准库） | 普通用户 |
| `wt` 采集进程 | 前台窗口、空闲、剪贴板、焦点文本采集 + 本地 HTTP 接收 | 普通用户 |
| 浏览器扩展 | Chrome/Edge MV3，上报当前页标题/URL/可见文字/选中 | 普通用户 |
| 批处理管线 | 每日一次：分段、聚类、命名、生成报表 | 普通用户 |
| 复核页 | 仅 `127.0.0.1:18732` 本地网页 | 普通用户 |
| 本地 LLM（可选） | `llama-server.exe` + GGUF 模型，仅监听 127.0.0.1 | 普通用户 |

- 不安装 Windows 服务、不安装驱动、不写系统目录、不修改组策略；
- 唯一系统改动：在当前用户「启动」文件夹增加一个快捷方式（最小化运行采集脚本），
  不写注册表；另可选在桌面增加一个打开本地界面的快捷方式；两者均可随时删除；
- 所有通信仅限本机回环地址；
- 卸载：`uninstall-user.bat` 删除自启快捷方式（及旧版 Run 项），删除文件夹即完成卸载。

## 2. 数据采集清单

| 数据项 | 来源 | 示例 | 是否存储 | 保存期 | 用途 |
|---|---|---|---|---|---|
| 程序名 | Win32 API | `Excel` | 是 | 30 天 | 时间线 |
| 窗口标题 | Win32 API | `P2401_成本测算.xlsx - Excel` | 是 | 30 天 | 区分任务 |
| 浏览器 URL / 页面标题 | 扩展 | `https://erp.../order/20241112-0032` | 是 | 30 天 | 区分页面 |
| 当前视口可见文字 | 扩展 | 订单号、客户名（≤1200 字） | 是（截断） | 30 天 | 识别事项 |
| 页面选中文字 | 扩展 | 选中的单号 | 是（≤300 字） | 30 天 | 识别事项 |
| 剪贴板文字 | Win32 API | 复制内容的**前 240 字 + 哈希** | 是（不含全文） | 7 天 | 关联复制/粘贴 |
| 焦点控件文本 | UI Automation | Excel 单元格、邮件正文（≤300 字） | 是 | 30 天 | 判断在做什么 |
| 空闲状态 | Win32 API | 超过 120 秒无输入 | 是 | 30 天 | 有效工时 |
| 时间线/任务标签 | 本机计算 | 09:12–09:31 核对订单 | 是 | 30 天 | 报表 |

**明确不采集**：原始按键内容（无键盘钩子）、屏幕截图（默认关闭）、文件内容、
密码框内容、浏览器无痕模式内容、网络数据包、通讯录、任何与工作无关的私人内容。

**敏感处理**：剪贴板只存哈希与前 240 字；检测到私钥块、`password=...` 等样式
直接跳过；密码管理器窗口的复制不记录；网站/程序可加入黑名单。

## 2.1 采集范围开关与权限预设

不同岗位/公司的允许范围不同，工具提供四档预设与逐项开关（复核页右上角「⚙ 采集设置」）：

| 预设 | 窗口标题 | 浏览器标题/URL | 网页正文 | 焦点输入 | 剪贴板 | 默认保留 |
|---|---|---|---|---|---|---|
| 严格 strict | — | — | — | — | — | 7 天 |
| 仅元数据 metadata | ✓ | ✓ | — | — | — | 14 天 |
| 标准 standard | ✓ | ✓ | ✓ | ✓ | 前 240 字 | 30 天 |
| 完整 full | ✓ | ✓ | ✓ | ✓ | 前 500 字 | 90 天 |

- 逐项开关：窗口标题、浏览器标题、URL、网页正文/选中文字、焦点输入、剪贴板、空闲检测；
- 排除名单：`privacy.excluded_apps`（如银行、密码管理器）、`privacy.excluded_domains`；
- 管理员锁定：`policy.locked = true` 后，复核页开关只读，用户不能自行放开采集范围；
- 浏览器扩展侧也可独立关闭「页面标题 / URL / 可见文字 / 选中文字」上报；
- 关闭的采集项立即停止写入（历史数据不回溯删除，可按保留期清理）；
- 切换采集类开关需重启采集进程生效，显示类开关刷新页面生效。

## 3. 网络行为与验证方法

- 监听：`127.0.0.1:18731`（接收浏览器扩展）、`127.0.0.1:18732`（复核页）；
  可选 `127.0.0.1:8080`（本地 LLM）；
- **无任何主动外联**；无遥测、无自动更新、无云端同步；
- 断网状态下采集、处理、出报表全部可用（仅首次下载/拷贝模型需要离线介质）；
- 扩展只向 `http://127.0.0.1` 发送，且带本地随机 token 校验。

验证方法（试点时由 IT 执行）：

```powershell
# 1) 只看回环监听，无外联目标
Get-NetTCPConnection -OwningProcess (Get-Process python*).Id -ErrorAction SilentlyContinue |
  Select-Object LocalAddress, LocalPort, RemoteAddress, State

# 2) 资源监视器 → 网络，观察进程无外部连接
# 3) 防火墙临时断开外网后运行 process-today.bat，确认报表正常生成
```

## 4. 权限、文件与系统改动

- 运行身份：当前普通用户（非管理员）；
- 文件：`%LOCALAPPDATA%\WorkTime\`（程序、数据、日志、报表）；
- 数据：`data\worktime.db`（SQLite，默认仅当前用户可访问的 NTFS 权限）；
- 启动：当前用户「启动」文件夹快捷方式，登录后最小化运行 `run-collector.bat`；
  任务栏可见一个最小化控制台窗口，关闭窗口即停止采集（透明、可审计）；
- 日志：`data\logs\collector.log`（2MB×3 轮转）；
- 卸载：删除 Run 项 + 删除文件夹；`uninstall-user.bat /D` 同时删除数据。

## 5. 安全与隐私控制

| 控制项 | 措施 |
|---|---|
| 数据本地 | 全部落盘本机；无上传通道；无遥测 |
| 访问控制 | 依赖 Windows 用户目录 NTFS 权限；建议同时启用 BitLocker 或 EFS |
| 最小化 | 只存必要文本、截断长度、剪贴板不存全文 |
| 敏感跳过 | 私钥/口令样式检测、密码管理器黑名单、无痕模式不采集 |

| 可删除 | 用户可随时删除 `data` 目录或卸载 |
| 界面内容默认隐藏 | 复核页默认不显示复制/粘贴/输入/网页正文，需手动打开开关；导出的日报/CSV/XLSX 不含这些原始内容 |
| 透明 | 复核页可查看每一条记录；日志可审计 |
| 代码可审 | MIT 许可，源码随包提供；组件清单见 `docs/components.md` |
| 完整性 | 交付 zip 提供 SHA-256；建议 IT 用哈希白名单放行（无数字签名） |

> 未做代码签名。若贵司要求签名/白名单，请以第 0 节 SHA-256 为准；
> 每次更新版本会重新提供哈希。

## 8. 试点方案与验收指标

- 范围：1 台目标电脑、1 个账号、连续 10 个工作日；
- 阶段：第 1–2 天只采集不整理；第 3 天开始每日复核 3–5 分钟；
- 验收指标：
  - 常驻资源：CPU < 1%、内存 < 100MB；
  - 稳定性：10 个工作日无崩溃、无数据丢失；
  - 数据完整率：应有工作时段覆盖率 ≥ 95%；
  - 命名准确率：人工复核后事项归属正确率 ≥ 80%；
  - 复核耗时：≤ 5 分钟/天；
  - 无外联：网络监控确认无外部连接。
- 回滚：`uninstall-user.bat` + 删除文件夹，5 分钟内完成。

建议审批范围（企业受限模式）：

```json
{
  "policy": { "preset": "enterprise", "locked": true },

```
