# WorkTime for Android v0.1.0（仅采集）

手机端先解决“采得到、导得出”，时间线/规则/报表仍在电脑端跑（同一套核心，口径一致）。

## 这个版本做什么

- 用系统 `UsageStatsManager` 记录**前台应用与时长**（不需要 root，不需要无障碍服务）
- 本地 SQLite（与桌面同表结构），手机端只读「今天各应用用时」
- 暂停 / 继续采集；前台服务 + 常驻通知
- 导出 `worktime-raw` JSON（复制到剪贴板或分享到微信/网盘/邮件）

## 安装

1. 下载下面的 `WorkTime-android-0.1.0-debug.apk`（debug 签名，仅自用/内测）
2. 安装后打开，点「授予使用情况访问」→ 系统设置里允许 WorkTime
3. 点「开始采集」，手机放一边正常用；一分钟回来看今日用量

## 导回电脑

```bat
wt import-raw --file worktime-raw-2026-11-13.json
wt process --date 2026-11-13
wt report --date 2026-11-13
```

## 不做/已知限制

- 不采集窗口标题、输入内容、剪贴板（需要无障碍服务，权限更重，后续版本再加）
- 国产 ROM 可能杀后台：把 WorkTime 加入「电池 → 不受限制」白名单
- 仅 debug 签名；上架或长期使用需要正式签名
