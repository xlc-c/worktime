# 隐私说明（给使用者）

WorkTime 是一个在本机运行的工作时间统计工具。这份说明告诉你它**采集什么、
不采集什么、数据存在哪里、你能怎么控制它**。

## 1. 采集什么

| 数据 | 例子 | 用途 |
|---|---|---|
| 前台程序名与窗口标题 | `Excel` · `P2401_成本测算.xlsx - Excel` | 构建时间线 |
| 浏览器页面信息 | 网址、页面标题、当前视口可见文字、你选中的文字 | 区分"同一浏览器里的不同事" |
| 剪贴板文字 | 复制内容的前 240 个字符 + 哈希 | 关联跨程序操作（复制→粘贴） |
| 焦点控件文本 | Excel 单元格内容、Outlook 邮件正文、Lync 输入框 | 判断正在处理什么 |
| 空闲状态 | 键盘鼠标无输入超过 2 分钟 | 区分"在工作"和"离开" |
| 屏幕使用时长 | 活跃/离开时长 | 计算有效工时 |

## 2. 不采集什么

- **不记录原始按键**（没有键盘钩子，中文输入法下也没有意义）；
- **默认不截屏**（没有屏幕截图，只有文本）；
- **不记录密码框内容**；检测到私钥、`password=...` 等样式的内容会直接跳过；
- 密码管理器（KeePass、Bitwarden、1Password 等）窗口里的复制不记录；
- 浏览器无痕模式不记录；
- 不采集文件内容本身，只采集窗口标题里的文件名。

## 3. 数据存在哪里

- 只存在本机：`data/worktime.db`（SQLite）和 `data/reports/`、`data/exports/`；
- 全部是本机 `127.0.0.1` 通信，**没有任何外联**；断网也能完整运行；
- 数据目录默认只允许当前 Windows 用户访问（NTFS 权限）。

## 3.1 界面里的内容显示

- 复核页默认**隐藏**复制/粘贴、焦点输入、网页正文，需要手动打开右上角
  「显示复制/粘贴/输入内容」开关才会显示；
- 导出的日报（Markdown）、CSV、XLSX **不包含**这些原始内容，只有任务/事项/时间/应用等统计信息。

## 3.2 采集范围与权限预设

不同人可以按自己的要求收紧采集范围（复核页右上角「⚙ 采集设置」）：

| 预设 | 记录什么 |
|---|---|
| 严格 strict | 只记应用名、时间、空闲；不记标题/URL/正文/焦点文本/剪贴板 |
| 仅元数据 metadata | 应用名 + 窗口标题 + 浏览器 URL；不记网页正文、焦点文本、剪贴板 |
| 标准 standard | 标题 + URL + 网页正文 + 焦点文本 + 剪贴板前 240 字 |
| 完整 full | 同标准，但预览更长、保留更久（个人使用） |

还可以逐项开关：窗口标题、浏览器标题、URL、网页正文/选中文字、焦点输入、剪贴板、空闲检测；
设置排除的程序（如银行/密码管理器）和排除的网站域名；调整原始数据与剪贴板记录的保留天数。
如果公司有统一策略，IT 可在 `config.json` 里设置 `policy.locked = true`，锁定这些开关，
用户侧只能查看不能修改。浏览器扩展也有独立开关，可只上报 URL/标题、不上报正文和选中文字。

## 4. 保存多久

- 原始活动记录与时间线：默认 **30 天**，程序启动时自动清理；
- 剪贴板记录：默认 **7 天**；
- 可随时修改 `config.json` 里的 `privacy.retention_days` 和
  `store_raw_clipboard_days`；也可以直接删除 `data` 目录。

## 5. 谁能看

- 只有能登录你这台电脑、且能访问你用户目录的人；
- 工具本身不提供任何远程上传、共享或导出到网络的通道；
- 生成的 Markdown/CSV/XLSX 是否发给别人，由你决定。

## 6. 你可以怎么控制

- 临时停止：退出采集进程（任务管理器里结束 `python`/`pythonw`，或重启电脑后不启动）；
- 永久停止：运行 `uninstall-user.bat` 删除开机自启；`uninstall-user.bat /D` 连数据一起删；
- 暂停某个网站：在浏览器扩展的"选项"里把它加入"不记录的网站"；
- 暂停某个程序：把程序加入 `clipboard_exclude_apps`（剪贴板）或告知管理员扩展黑名单；
- 修正标签：打开复核页改任务/事项，改一次后同类活动会自动沿用。

## 7. 给公司/管理者的说明

如果这个工具用于**员工工时管理**，请先完成：
知情告知（全员）、制度依据、处理目的与范围说明、最小必要评估、
以及《个人信息保护法》要求的相关流程；详细内容见 `docs/IT-审批材料.md`。
仅用于**个人自我时间管理**时，只需要完成软件安装审批与个人信息告知。
