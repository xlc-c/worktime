# 用 AI 做推广：可执行工作流（不泄露隐私）

> 说明：我（当前这个 AI）**不能直接登录微信/QQ/Discord/Reddit/X 等第三方账号**发帖。
> 但可以把“AI 生成内容 + 你一键发布”的流程做到最省力；如果某些平台提供 API 且你愿意授权，
> 也可以逐条代发（不批量刷屏）。

## 1. 让 AI 写各平台文案（提示词模板）

把下面提示词复制到你常用的 AI 里（ChatGPT / Claude / Copilot / 豆包 / Kimi / 通义），
一次生成一个平台，避免一稿多投：

```text
你是开源项目推广助手。项目：WorkTime，Windows 本地工作时间线工具，MIT 开源。
卖点：自动时间线、拖动打标签、打断识别、日/周/月/年报、四档采集权限、完全本地无遥测。
我要发在【平台/群类型】，受众是【开发者/效率爱好者/公司 IT/普通办公族】。
请写一条【字数】字以内的中文帖子，语气像真实用户分享而不是广告：
1) 开头用具体痛点；2) 中间 3 个功能点；3) 结尾是“想找内测/求建议”；
4) 附 1 个链接占位符 {LINK} 和 1 张模拟数据截图建议；5) 不要夸大、不要承诺效果。
```

生成后人工改两句口语，避免 AI 味；**不要**让 AI 接触你的真实工作数据。

## 2. 发布节奏（避免被当广告）

| 时间 | 平台 | 内容 |
|---|---|---|
| Day 1 | GitHub Release + Discussions | 英文 release notes + “looking for beta testers” |
| Day 1 | Show HN | 英文，隐私/local-first 角度 |
| Day 2 | V2EX 分享创造 + 少数派 | 中文，讲“为什么做 + 隐私设计 + 数据” |
| Day 3 | Reddit r/selfhosted 或 r/Windows11 | 选一个，遵守版规，回评论 |
| Day 4 | AI 群/微信群/Discord | 短版求助文案，发模拟截图 + Release 链接 |
| Day 5 | 即刻/知乎想法 | 一张图 + 3 句话，引流到 GitHub |
| Week 2 | Product Hunt | 等英文 UI 完成后再发 |

**同一个链接一天只发 1–2 个地方**；先回评论再发下一条；每个平台用不同开头。

## 3. 让 AI 帮你回评论

把公开评论贴给 AI（**去掉对方个人信息**），提示词：

```text
下面是用户对开源工具 WorkTime 的反馈。请帮我写一条 60 字以内的回复：
先确认问题/感谢，再说明下一步（复现/已记录 issue/下个版本），不要过度承诺。
反馈：{feedback}
```

## 4. AI 在“软件内”的推广方式

- **GitHub Copilot / Cursor 等**：在 README 里放 “Good first issues”，让 AI 辅助贡献者上手；
- **Discord/Telegram 的 AI bot**：给社区 bot 提供项目 FAQ（SHARE.md / BETA.md），让 bot 自动回答；
- **公众号/知乎的 AI 写作工具**：用上面的提示词生成初稿，人工润色后发布；
- **邮件/Newsletter**：给测试者发“本周更新”，用 AI 汇总 changelog（只发项目信息）。

## 5. 隐私底线（必须遵守）

- 不让任何第三方 AI 接触：`data/`、`config.json`、token、真实窗口标题/剪贴板；
- 截图只用 `docs/screenshots/` 的模拟数据；
- 发群/论坛前检查图片里没有客户名、路径、邮箱；
- 不买量、不刷评论、不群发骚扰；遵守各平台规则；
- 如果授权我使用某个平台 API，只发**一条** launch 帖，不自动批量发。

## 6. 可授权的自动化（可选）

如果你希望我“自己发”，需要：

1. 本机完成 `gh auth login`（GitHub 部分我可以直接操作：建仓库、Release、Discussions）；
2. 其他平台（X/Reddit/Dev.to）需你创建 API token 并**在本机环境变量**里配置，
   我不会把 token 写进代码或聊天；每次只发一条，先给你预览。

没有授权时，我会把文案、图片、排期准备好，你复制粘贴即可。
